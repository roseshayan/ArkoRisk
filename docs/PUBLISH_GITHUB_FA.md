# چک‌لیست انتشار ArkoRisk در GitHub

## 1. ساخت مخزن

- یک Repository عمومی با نام پیشنهادی `ArkoRisk-MT5` بسازید.
- توضیح پیشنهادی: `Open-source risk, position and prop-firm manager for MetaTrader 5.`
- Topics پیشنهادی: `metatrader5`, `mql5`, `risk-management`, `position-sizing`, `prop-firm`, `forex`, `scalping`.

## 2. بررسی پیش از Push

- فایل `ArkoRisk.mq5` را با MetaEditor 5 کامپایل کنید.
- هدف انتشار: `0 errors, 0 warnings`.
- Market و Limit را روی Demo تست کنید.
- لینک‌ها، ایمیل و Telegram را بازبینی کنید.
- هیچ EX5 ناشناس، Log، Screenshot ژورنال یا اطلاعات حساب Commit نکنید.

## 3. GitHub Pages

لندینگ‌پیج در ریشه مخزن قرار دارد. از `Settings → Pages`، گزینه Deploy from a branch را انتخاب و Branch اصلی با Folder `/ (root)` را فعال کنید.

## 4. اولین Release

- Tag: `v1.40`
- Title: `ArkoRisk MT5 v1.40 — Stable Open-Source Release`
- فایل ZIP بسته آماده را به Release اضافه کنید.
- در Release Notes خلاصه CHANGELOG، هشدار تست Demo و روش نصب را بیاورید.

## 5. بعد از انتشار

- Issue Templates را فعال نگه دارید.
- گزارش‌ها را با نسخه MetaTrader، Broker، Symbol و نوع Account درخواست کنید.
- برای تغییرات ارسال سفارش یک نسخه آزمایشی جدا و تست Demo داشته باشید.
